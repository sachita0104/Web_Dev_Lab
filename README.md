# Web Dev Lab - My Portfolio Project

A responsive, semantic personal portfolio website built from scratch as part of my Web Development Lab coursework.

## 🚀 Features
- **Semantic HTML5** structure for accessibility and SEO.
- **CSS Design Tokens** for consistent typography and spacing.
- **Advanced Layouts** using CSS Flexbox and CSS Grid.
- **Responsive Design** that adapts to mobile, tablet, and desktop screens.
